# DSP-library

A repository where I implement DSP algorithms and tools mentioned in John G. Proakis Digital Signal Processing. The aim for this repository is to get more accustomed to C while studying in depth examples of DSP algorithms and phenomenon.

Current experiments include:

* Radar pulse compression using chirp signals
* Chapter 1: Sampling and resampling
* Chapter 2: Radar distance resolution and calculation
* Chapter 3: Inverse Z-transform and ROC
